# mnemo-server

`mnemo-server` is the future transport-adapter package for Mnemo. Version 0.12.0
remains a transport scaffold; REST, WebSocket, and MCP implementations are
assigned to later roadmap phases. It owns the explicit installation-layer
`mnemo provision-tokenizer` command; core runtime chunking stays offline.

See the [Mnemo repository](https://github.com/atharvpatil2748/Mnemo) for the
architecture, roadmap, documentation, and contribution guidance.
