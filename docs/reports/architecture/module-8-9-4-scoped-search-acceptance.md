## Internal implementation and authority

`ScopedSearchApplicationService` in `mnemo-server/mnemo_server/services/scoped_search.py` is an internal adjacent orchestration layer over the existing `SharedSearchApplicationService`; it is not imported by an HTTP router or MCP tool. `ScopedSearchAuthorization` in `services/shared_search.py` resolves the trusted principal against the SQLite ACL, checks every selected notebook, checks each explicit notebook/document/version tuple through the existing source association resolver, and revalidates before disclosure. An empty all-authorized scope and an explicitly unauthorized or nonexistent notebook fail without provider search. Legacy-unassigned notebooks are not granted access.

Before running providers, the authorization layer inspects composed representations and read-only active generation, coverage, checksum, and source-version metadata. It distinguishes active, not-applicable, unavailable, incomplete, and incompatible states per notebook. A composed multilingual source without a governed Full V2 alias is not admitted; legacy `language_text` aliases are not substituted for `language_text_v2`. The admission matrix and ACL revisions are rechecked after work. Provider execution still owns its own readiness and snapshot checks. No production generation was activated.

Ranked fan-out uses one server-owned candidate budget, response-byte ceiling, elapsed deadline, and four concurrent tasks. Each exact document/version tuple is a separate child retrieval scope, preventing an independent document-ID/version-ID cross-product. The existing V2 evidence service executes each child. Results are interleaved by notebook, then by document partition, without deduplicating away distinct notebook memberships. No raw BGE/CLIP scores are compared at this layer. A provider failure is distinguished from searched-zero, and non-admitted or budget-omitted sources produce explicit omissions. Ranked top-k is never labelled exhaustive.

Traversal uses an internal signed aggregate cursor distinct from existing single-notebook cursors. It binds trusted actor, selected notebook/revision vector, exact document/version tuples, normalized query, representation policy, active alias matrix and effective limits. Its per-partition state vector stores child cursor positions, source snapshots and source-status digests; every partition is revalidated before any item is returned on a continuation. Active partitions rotate across pages so a large first notebook cannot monopolize requested-k. Completed partitions are replayed within the global call/byte/deadline budget. Expired, tampered, cross-principal, changed-query/limit/representation, stale ACL, or changed source snapshots fail rather than restarting. Aggregate cursor size and partition count are bounded. The mechanism remains internal and does not change V1/V2 public cursor contracts.
