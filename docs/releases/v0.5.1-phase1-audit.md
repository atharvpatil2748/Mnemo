# Mnemo 0.5.1 — Phase 1 Audited Baseline

Mnemo 0.5.1 is the verified Phase 1 engineering baseline. It includes the
from-scratch core domain, contract, registry, configuration, and composition
foundations required before storage work begins.

## Included

- Immutable domain models for documents, blocks, chunks, assets, graph,
  notebooks, conversations, citations, and retrieval results.
- Seven versioned, transport-independent provider contracts and shared typed
  records and exceptions.
- Semantic-version-aware plugin registration, discovery, priority ordering,
  conflict handling, lifecycle freezing, and immutable metadata.
- Frozen TOML and environment configuration with explicit storage, LLM,
  embedding, reranker, and plugin sections.
- Atomic `KnowledgeEngine` composition, required-provider validation,
  lifecycle state, rollback, capability inspection, and in-memory shutdown.

## Audit corrections

- Package metadata now reports 0.5.1 consistently.
- Architecture, roadmap, ADR integration notes, and changelogs are synchronized
  with the accepted Phase 1 contracts.
- Docker configuration uses canonical ADR-0003 environment names.
- CI now verifies Python distribution builds and supports manual audit runs.
- README, contribution guidance, conduct policy, and GitHub templates establish
  the open-source project baseline.

## Quality

The release is gated by Ruff, strict mypy, pytest with at least 90% coverage,
pre-commit, frontend format/lint/typecheck/test/build, Python wheel and sdist
builds, package metadata inspection, Compose validation, and Docker image
builds.

## Scope boundary

This is not yet a functional document-retrieval release. Concrete storage,
parsing, chunking, embedding, retrieval, REST, MCP, and product UI behavior are
assigned to later roadmap phases. Phase 2 has not started.
