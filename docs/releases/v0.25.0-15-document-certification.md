# Mnemo v0.25.0 — 15-Document Production Certification

Mnemo v0.25.0 expands its production-ingestion certification to fifteen
heterogeneous documents and adds production XLSX parsing.

Highlights:

- Fresh production ingestion of PDF, source code, CSV, XLSX, PPTX, DOCX, and
  Markdown sources.
- 15 documents, 1,514 canonical chunks, synchronized FTS/title projections,
  and 1,514 validated 768-dimensional embedding-cache identities.
- Generic fixes for PDF table-adjacent and mixed-font content preservation.
- Hardened retrieval provenance, embedding-cache lifecycle, metadata
  serialization, streaming errors, and MCP SSE configuration precedence.
- Live HTTP, streaming, MCP stdio/SSE, six-tool, retrieval, grounded Final-QA,
  citation, persistence, and immutable replay validation.
- Complete Python, frontend, Docker, typing, linting, and package-build gates.

The certified local profile intentionally uses SQLite sparse/title retrieval
with Qdrant disabled. Qdrant-backed dense retrieval remains deployment
dependent.

See `docs/audit_report_phase0-8-final.md` and
`docs/changelog/0062-15-document-production-certification-v0.25.0.md` for the
full evidence and known P3 residual risks.
