# Mnemo Module Documentation

Implementation, contradiction, readiness, and closure reports are grouped by
their major module:

- [Module 6](module-6/) — retrieval, reranking, context, citations, and Final QA
- [Module 7](module-7/) — server and transport implementation records
- [Module 8](module-8/) — MCP implementation and integration records

These are engineering records for their module stage; current production truth
is documented by the [final certification](../reports/certification/current/mnemo-v2-final-certification.md).
