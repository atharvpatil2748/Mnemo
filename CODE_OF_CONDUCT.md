# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Mnemo a harassment-free experience for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience,
education, socioeconomic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behavior

- Be respectful, constructive, and precise.
- Welcome differing experience levels and technical perspectives.
- Focus criticism on ideas and implementations, never people.
- Respect privacy and avoid publishing another person's private information.
- Accept responsibility, apologize, and correct harm when mistakes occur.

Harassment, discriminatory language, threats, unwanted sexual attention,
trolling, and sustained disruption are unacceptable in project spaces.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions
that violate this code. Report conduct concerns privately to the repository
owner through their GitHub profile. Maintainers will review reports promptly,
protect reporter privacy as far as practical, and apply proportionate action.

This code applies in project spaces and when representing the project publicly.
It is adapted from the Contributor Covenant, version 2.1.
