# mnemo-core

`mnemo-core` is the core Python library implementation of the Mnemo
local knowledge engine. Version 0.10.8 contains the audited Phase 1 foundation,
the corrected Phase 2 storage subsystem, and Phase 3 through the Module 3.9
ingestion/canonicalization bridge. Chunking and retrieval belong to later phases.

See the [Mnemo repository](https://github.com/atharvpatil2748/Mnemo) for the
architecture, roadmap, documentation, and contribution guidance.
