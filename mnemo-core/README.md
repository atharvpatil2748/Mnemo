# mnemo-core

`mnemo-core` is the core Python library implementation of the Mnemo
local knowledge engine. Version 0.20.1 contains the audited Phase 1 foundation,
the corrected Phase 2 storage subsystem, Phase 3 through Module 3.9, the
complete Phase 4 V2 dispatcher and all nine document-aware chunking strategies
through Module 4.10, and the complete Phase 5 embedding pipeline (OllamaEmbedder,
SQLite embedding cache, and EmbedderModule). Retrieval remains Phase 6.

See the [Mnemo repository](https://github.com/atharvpatil2748/Mnemo) for the
architecture, roadmap, documentation, and contribution guidance.
