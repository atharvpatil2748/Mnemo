# mnemo-core

`mnemo-core` is the pure Python, transport-independent foundation of the Mnemo
local knowledge engine. Version 0.5.1 contains the audited Phase 1 domain,
interface, registry, configuration, and composition contracts. Concrete
storage, parsing, and retrieval implementations belong to later phases.

See the [Mnemo repository](https://github.com/atharvpatil2748/Mnemo) for the
architecture, roadmap, documentation, and contribution guidance.
